Rede Neural Convolucional classificadora de imagens de entrada de gatos e cachorros.

O dataset está disponível no site: https://www.kaggle.com/competitions/dogs-vs-cats

No código, estão escritos os métodos para salvar o algoritmo treinado, e, após o treino completo,
carregar o modelo salvo.

PS: para salvar o dataset, salve as pastas de Dog e Cat dentro de outra pasta geral.
